## The problem

AIPPT is a Python platform that turns Markdown and JavaScript into PowerPoint decks. Teams still spent a lot of time drafting and reviewing presentations by hand.

## What I did

- Took ownership of **AIPPT** and added **AI-powered deck generation** and **deck reviews**.
- Independently built **four AI agents**:
  - a chatbot assistant
  - an AI news ingestion agent
  - a GitHub pull request automation agent
  - a presentation analytics agent using the **Microsoft Graph API**
- Extended an agentic document review tool with paper ingestion, adversarial review, rubric-based analysis, and automated response drafting.

## Results

- Early users report saving **more than an hour per presentation**.
